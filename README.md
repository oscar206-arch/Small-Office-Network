\# Small Office Network



\## Overview



A small office network design and implementation project built

in Cisco Packet Tracer. The project simulates a business network

that separates Administration, Staff, and Guest devices using

VLANs, with inter-VLAN routing to enable controlled communication

between networks.



\## Problem Statement



A flat network can make it difficult to separate departments,

manage network traffic, and restrict guest access to internal

business resources.



\## Objectives



\- Design a functional small office network.

\- Segment departments using VLANs.

\- Configure IPv4 addressing and default gateways.

\- Implement inter-VLAN routing.

\- Test connectivity and explore network security controls.



\## Technologies



\- Cisco Packet Tracer

\- Cisco IOS CLI

\- VLANs and IEEE 802.1Q trunking

\- IPv4 addressing and routing



\## Network Segmentation



| VLAN | Department | Network |

|---|---|---|

| 10 | Administration | 192.168.10.0/24 |

| 20 | Staff | 192.168.20.0/24 |

| 30 | Guest | 192.168.30.0/24 |



\## Project Status



VLAN configuration, IP addressing, router subinterfaces,

trunking, and gateway connectivity have been implemented

and tested. Inter-VLAN connectivity testing and guest network

access controls remain to be completed.



\## Learning Outcomes



Practical experience in network design, VLAN configuration,

routing, connectivity testing, and network troubleshooting.
